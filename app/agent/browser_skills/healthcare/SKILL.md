# Healthcare Skill

## FOR FINDING DOCTORS: Navigate to https://www.zocdoc.com

## PROCEDURE:
1. Navigate to Zocdoc
2. Enter specialty or doctor name in search
3. Enter location (city or zip)
4. Apply filters: insurance accepted, availability, rating
5. Browse results — extract: name, specialty, rating, next available, address
6. Present top options with availability

## FOR HEALTH INFORMATION: Navigate to https://www.webmd.com

## FOR MEDICATION PRICES: Navigate to https://www.goodrx.com
1. Search for medication name
2. Enter zip code for local pharmacy prices
3. Extract: pharmacy name, price with GoodRx coupon, original price
4. Present cheapest options

## COMMON PITFALLS:
- Zocdoc requires location — always provide one
- Insurance filtering is crucial — "accepting new patients" matters
- Medication prices vary widely by pharmacy — always compare
- Do NOT provide medical advice — only present factual information from the website
