# Automotive Skill

## FOR CAR SHOPPING: Navigate to https://www.cars.com or https://www.cargurus.com

## PROCEDURE:
1. Navigate to Cars.com or CarGurus
2. Select: New/Used, Make, Model, zip code, price range
3. Search and browse listings
4. Extract: year, make, model, trim, mileage, price, dealer, location
5. For comparison, check KBB (kbb.com) for fair market value
6. Present top options with pricing context (good deal vs overpriced)

## COMMON PITFALLS:
- Dealer prices may not include documentation/destination fees
- "No-haggle" price on Carvana/Vroom is final; dealer prices are negotiable
- Check vehicle history via Carfax link if available in listing
