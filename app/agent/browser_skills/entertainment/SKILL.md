# Entertainment Skill

## FOR MOVIES/TV: Navigate to https://www.justwatch.com
- JustWatch shows WHERE to stream any movie/show across all platforms
- Search → see which streaming services have it

## FOR MOVIE INFO: https://www.imdb.com
## FOR REVIEWS: https://www.rottentomatoes.com

## PROCEDURE:
1. Search for the movie/show/game
2. Extract: title, year, rating, genre, where to watch, cast
3. If comparing, check both IMDb (audience) and Rotten Tomatoes (critics)
4. For "what should I watch" queries, check trending/popular sections

## COMMON PITFALLS:
- Streaming availability varies by country
- JustWatch is the best single source for "where to stream"
- IMDb ratings (1-10) and RT scores (percentage) are different scales
